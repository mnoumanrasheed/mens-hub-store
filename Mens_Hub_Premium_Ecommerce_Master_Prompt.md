# 4. Main Problems to Fix

## A. Internal Heroes Are Visually Inconsistent and Overdesigned

The current internal pages use a cinematic hero system with multiple route-specific visual variants, dual rotated images, index numbers, decorative material cards, editorial labels, and full-viewport height.

Examples of artificial decorative copy currently generated by the shared internal hero include:

- `Material / form / function`
- `Men's Hub / 04`
- `Menswear / Objects / Details`
- `Selected pieces / 02`
- `New season / 01`
- `Client services / 01`

This makes the site feel like an AI-generated fashion portfolio instead of a usable premium ecommerce store.

### Fix

Create **ONE coherent internal hero design system** and use it consistently on:

- category pages
- New Arrivals
- Sale
- About
- Contact where appropriate

Internal heroes should NOT be `100svh`.

Recommended target:

- desktop: approximately `460–620px`, or a controlled `55–65vh`
- tablet: approximately `420–520px`
- mobile: approximately `360–480px`
- never force the user to scroll a complete viewport before reaching products/content

Use a restrained structure:

**Eyebrow → H1 → short useful description → optional CTA → one strong editorial image**

Remove:

- fake editorial numbering
- vertical rotated indexes
- decorative slash copy
- floating “material” labels
- stacked rotated photograph cards
- excessive 3D perspective
- meaningless “scroll to explore” copy
- different hero composition rules for every route

A small image reveal or subtle 2–4px floating/parallax effect is acceptable only if it is understated and respects `prefers-reduced-motion`.

# 5. Typography Must Be Rebuilt for Readability

The current storefront contains many UI sizes around roughly 0.5–0.7rem. This is too small for normal navigation, buttons, metadata and ecommerce interaction.

Use **Manrope as the primary interface/type system**.

Cormorant Garamond may remain only as a restrained editorial accent for selected major hero headings if it genuinely improves the brand. Do not use it everywhere.

Recommended production scale:

| Element | Target |
|---|---:|
| Body text | 16px minimum |
| Secondary body | 14–15px |
| Nav links | 13–14px |
| Buttons/CTAs | 13–14px |
| Form labels | 13–14px |
| Product title | 15–17px |
| Product price | 15–17px |
| Eyebrows | 11–12px minimum |
| Breadcrumbs | 12–13px |
| Small metadata | 12px minimum |
| H1 internal | fluid 44–72px desktop |
| H1 mobile | fluid 36–52px |
| H2 | fluid 30–48px |
| H3 | fluid 22–32px |

Do not create fake luxury by making text tiny.

Maintain excellent contrast and line-height.

Functional UI should be readable at 100% browser zoom on a typical 1366px/1440px laptop.
